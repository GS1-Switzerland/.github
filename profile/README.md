GS1 Switzerland is part of the global GS1 network and supports companies in enabling interoperable, efficient and transparent value chains across industries. 
Our GitHub organization hosts technical artefacts, documentation and open-source components used or published by GS1 Switzerland. Learn more at [www.gs1.ch](https://www.gs1.ch)

---

## Purpose of this GitHub Organization

This space provides:

- Reference implementations and example configurations  
- Integration code and supporting libraries  
- Technical documentation  
- Resources related to GS1 standards, data exchange and web vocabularies

Each repository contains its own governance, contribution rules and security information.

## About GS1 Switzerland

GS1 Switzerland is a non-profit, industry-driven standardization organization.  
We support companies in improving data quality, collaboration and operational excellence across the entire value chain.  
We operate solutions in education, data management, product transparency, sector initiatives and digital services.
